# Portfolio - Personal Portfolio Website
This project is a personal portfolio website developed as part of the Portfolio 1 course at Noroff. It brings together selected coursework and projects in one place to showcase my development skills, experience, and progress as a front-end developer.

## Description
The portfolio was created to present my work in a clear and accessible way. It provides an overview of selected projects, the technologies I have worked with, and some information about my interests in front-end development.

The website uses a simple layout to make project information easy to navigate, with links to live demonstrations and source code.

## Key Features
- Responsive layouts for mobile, tablet, and desktop screens.
- A single-page portfolio layout with section-based navigation.
- Project presentations with descriptions and relevant links.
- Direct links to project repositories and live websites.
- Consistent visual styling and reusable layout elements.
- Clearly structured content.

## Built With

- HTML5 - Website structure and content
- CSS3 - Styling, layout, and responsive design
- JavaScript - Implementing a functional hamburger menu
- Figma - Design planning and visual references

## Run the Project Locally

### Requirements
You will need Git, a code editor such as Visual Studio Code, and a web browser.

### Setup

1. Clone the repository:

```bash
git clone https://github.com/LinxonXD/portfolio.git
```

2. Navigate to the project directory:

```
cd portfolio
```

3. Open the folder in Visual Studio Code

4. Install or enable the Live Server Extension, then launch index.html using Open with Live Server.

5. Open the local addess provided by Live Server in your browser. The port may vary depending on your configuration.
